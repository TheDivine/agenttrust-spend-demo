# Security policy

Only the current main branch is maintained. This is an experimental loopback-only simulator, not a production security boundary. See README for known limitations.

For sensitive reports, use GitHub's private vulnerability reporting feature if enabled on this repository. If it is unavailable, open an issue requesting a private reporting channel without exploit details or sensitive information. Do not submit tokens, real financial data or customer records.

There is no promised response SLA or bug bounty. Avoid tests against third parties. Use isolated synthetic local fixtures.
